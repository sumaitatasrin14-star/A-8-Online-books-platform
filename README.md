# 📚 BookSphere - Online Book Platform

BookSphere is a modern online book library platform built with **Next.js (App Router)** and **Tailwind CSS**.  
It allows users to explore books, view details, and borrow books with authentication.

---

## 🚀 Features

- 🔐 User Authentication (Login/Register)
- 🔒 Private Routes (Protected Pages)
- 📚 Book Listing with Search & Category Filter
- 📖 Single Book Details Page
- 📦 Borrow Book System
- 👤 User Profile Dashboard
- ✏️ Update Profile (Name & Photo)
- 🌙 Dark/Light Mode Toggle
- 🎨 Modern Responsive UI
- 🔔 Toast Notifications (Success/Error)
- 🎞️ Animations with Framer Motion
- 🖼️ Image Optimization with Next/Image

---

## 🛠️ Tech Stack

- Next.js 14 (App Router)
- React.js
- Tailwind CSS
- Firebase Authentication
- React Toastify
- Framer Motion
- SwiperJS (Slider)
